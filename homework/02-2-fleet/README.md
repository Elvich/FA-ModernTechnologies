Вариант А–Е (первая буква фамилии Г). Java 17+, Spring Boot, JPA/ORM, MySQL и HTML/CSS/JavaScript. Авторизация отключена по поручению пользователя.

## Запуск

Из корня репозитория:

```sh
export DB_USER=your_mysql_user
export DB_PASSWORD=your_mysql_password
./mvnw -pl homework/02-2-fleet spring-boot:run
```

Открыть <http://localhost:8082>. По умолчанию MySQL находится на `localhost:3306`, база `fleet`. При наличии разрешения на создание баз она создаётся автоматически. Можно заранее создать базу с кодировкой `utf8mb4`. Настройки подключения: `DB_URL`, `DB_USER`, `DB_PASSWORD`; порт приложения: `PORT` (по умолчанию 8082). Таблицы создаёт Hibernate. Учебный `ddl-auto=update` не заменяет миграции production-системы.

Для знакомства без установки MySQL:

```sh
./mvnw -pl homework/02-2-fleet spring-boot:run -Dspring-boot.run.profiles=demo
```

Профиль `demo` использует H2 в памяти; данные удаляются при остановке приложения. Основной профиль использует MySQL, данные сохраняются в базе.

## Что реализовано

- Добавление, просмотр, редактирование и удаление машины.
- Поиск без учёта регистра по марке, ФИО владельца, году, дате, ID и пробегу. Несколько полей проверяются одним поисковым запросом.
- Сортировка по году выпуска: изначально по возрастанию, доступно переключение по убыванию. При одинаковом годе записи упорядочены по ID.
- Счётчик строк, соответствующих текущему поиску.
- Гистограмма количества постановок на учёт за 7 календарных дней: сегодня и шесть предыдущих дней, включая дни без событий. Она учитывает весь автопарк и не зависит от поиска. Будущие и более ранние даты не входят в неё.
- Проверка ввода и сообщения об ошибках. Год ограничен диапазоном 1886..текущий год+1: это учебная проверка разумности года выпуска. Пробег неотрицательный. ФИО и марка обязательны. Дата регистрации обязательна; будущая дата разрешена для планируемой регистрации.

| Поле API | Назначение |
| --- | --- |
| `id` | Генерируется базой данных |
| `brand` | Марка, до 150 символов |
| `manufactureYear` | Год выпуска |
| `registeredOn` | Дата постановки на учёт, `YYYY-MM-DD` |
| `ownerName` | ФИО владельца, до 250 символов |
| `mileage` | Пробег в километрах, целое число |

## REST API

- `GET /api/cars?q=Toyota&direction=asc` - поиск и список; `direction` принимает `asc` или `desc`.
- `GET /api/cars/{id}` - одна машина.
- `POST /api/cars` - создание, код 201 и заголовок Location.
- `PUT /api/cars/{id}` - полная замена данных машины, код 200.
- `DELETE /api/cars/{id}` - удаление, код 204.
- `GET /api/cars/histogram` - массив из 7 объектов `{ "date": "2026-11-04", "count": 0 }`.

Тело POST/PUT:

```json
{
  "brand": "Toyota",
  "manufactureYear": 2020,
  "registeredOn": "2026-11-04",
  "ownerName": "Иванов Иван Иванович",
  "mileage": 45000
}
```

Некорректные данные возвращают HTTP 400, неизвестный ID - 404; тело содержит поле `message`. ID в теле запроса не задаётся.
