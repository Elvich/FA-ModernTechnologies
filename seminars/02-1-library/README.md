# Семинар 2-1. Библиотека

Вариант А–Е (фамилия на Г). Java 17+, Spring Boot, JPA/ORM, MySQL, HTML/CSS/JavaScript. По просьбе пользователя приложение без авторизации.

## Запуск

Из корня репозитория, с доступным MySQL:

```sh
DB_USER=fa DB_PASSWORD='ваш-пароль' ./mvnw -pl seminars/02-1-library spring-boot:run
```

URL базы по умолчанию `jdbc:mysql://localhost:3306/library?createDatabaseIfNotExist=true&useUnicode=true&characterEncoding=UTF-8`. Пользователю MySQL нужны права на базу `library`. Переменная `DB_URL` позволяет задать другое подключение. Пароль в репозитории не хранится.

Для демонстрации без MySQL:

```sh
./mvnw -pl seminars/02-1-library spring-boot:run -Dspring-boot.run.profiles=demo
```

Этот профиль использует H2 в режиме совместимости MySQL, с сохранением в `data/library`. Учебная целевая СУБД остаётся MySQL. Открыть <http://localhost:8081>.

## Работа с приложением

- Добавить книгу через форму; «Изменить» переносит запись в форму; «Удалить» запрашивает подтверждение.
- Поля: `id` (создаёт база), `title` (название), `publisher` (издательство), `issuedOn` (дата выдачи), `studentName` (ФИО студента), `returnedOn` (необязательная дата сдачи).
- Дата сдачи не может предшествовать выдаче. Название, издательство и ФИО обязательны, максимум 200 символов.
- Поиск без учёта регистра по всем полям, включая ID и ISO-даты `YYYY-MM-DD`. Счётчик отражает число найденных записей.
- Сортировка по дате выдачи по возрастанию по умолчанию, с возможностью переключить направление. Одинаковые даты упорядочены по ID.
- Гистограмма считает выдачи по всем книгам за сегодня и шесть предыдущих дней. Дни без выдач отображаются с нулём. Будущие даты и даты до периода не учитываются. Текущая дата показана в шапке.

## API

| Запрос | Назначение |
| --- | --- |
| `GET /api/books?q=...&direction=asc` | Поиск и сортировка (`asc` / `desc`) |
| `GET /api/books/{id}` | Одна книга |
| `POST /api/books` | Добавление, ответ 201 и заголовок Location |
| `PUT /api/books/{id}` | Редактирование |
| `DELETE /api/books/{id}` | Удаление, ответ 204 |
| `GET /api/books/histogram` | 7 объектов `{date,count}` по возрастанию даты |
| `GET /api/today` | Текущая ISO-дата сервера |

Тело POST/PUT:

```json
{"title":"Изучаем Java","publisher":"Учебное издательство","issuedOn":"2026-11-04","studentName":"Тестовый студент","returnedOn":null}
```

Ошибки полей и формата возвращают 400, отсутствующая книга - 404, тело ошибки содержит `message`.

## Проверки

```sh
./mvnw -pl seminars/02-1-library test
```

HTTP-интеграционные тесты запускают приложение на случайном порту и проверяют CRUD, поиск, сортировку, валидацию, ошибки, доступность страницы и границы семидневной гистограммы. Для изоляции тестов используется H2, а не рабочая база.
