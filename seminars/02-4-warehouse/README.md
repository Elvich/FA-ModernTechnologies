# Семинар 2-4: склад магазина техники

Вариант А–Е, поле `kind`, сортировка по дате ввоза по возрастанию, гистограмма за 7 дней. Без авторизации по уточнению автора задания.

## Запуск из корня репозитория

```sh
./mvnw -pl seminars/02-4-warehouse spring-boot:run
# Или деморежим без MySQL, данные исчезают при остановке:
./mvnw -pl seminars/02-4-warehouse spring-boot:run -Dspring-boot.run.profiles=demo
```

Интерфейс: http://localhost:8084. Основной профиль использует базу MySQL `warehouse`; `DB_URL`, `DB_USER`, `DB_PASSWORD` задаются окружением (см. корневой README). Деморежим - H2 в памяти.

## Поля и поведение

- `id`: генерируемый идентификатор.
- `kind`: вид техники (обязательно, до 200 символов).
- `equipmentGroup`: группа техники (обязательно, до 200 символов).
- `importedOn`: дата ввоза (обязательно).
- `exportedOn`: дата вывоза (необязательно; не раньше ввоза).
- `driverName`: ФИО водителя (обязательно, до 200 символов).

Одна запись соответствует одной единице техники. Гистограмма считает именно вывезенные единицы по `exportedOn`, а не поступления. Неотгруженная техника и даты вне интервала не учитываются. Дни с нулевым числом отгрузок отображаются.

## REST API

| Метод | URL | Назначение |
| --- | --- | --- |
| GET | `/api/equipment?q=&order=asc` | Поиск по всем полям, сортировка по дате ввоза asc/desc и ID |
| GET | `/api/equipment/{id}` | Одна запись |
| POST | `/api/equipment` | Добавить (201) |
| PUT | `/api/equipment/{id}` | Изменить (200) |
| DELETE | `/api/equipment/{id}` | Удалить (204) |
| GET | `/api/equipment/histogram` | Массив `{date,count}`, 7 дней включая сегодня |

POST/PUT принимают JSON с полями выше. ID из тела при создании игнорируется, при изменении берётся из URL. Неверный ввод возвращает 400, отсутствующий ID - 404. Поиск не учитывает регистр. Счётчик показывает число видимых записей, гистограмма - всю базу.

Проверки: `./mvnw -pl seminars/02-4-warehouse test`. Тесты используют H2 MODE=MySQL, HTTP и JPA, проверяют CRUD, сортировку, поиск, границы гистограммы, пропущенные дни, неверные даты и 404.
